# Формула описания

## Структура
1. **Первая строка (≤ 6–8 слов + 👇)** — продолжает хук, а не повторяет его. Видна до «ещё».
2. **Суть (1–2 предложения)** — какая боль и что изменилось.
3. **Шаги или список (3–5 пунктов)** — ▫️ или 1️⃣2️⃣3️⃣, коротко, конкретно, с названиями кнопок.
4. **Призыв:** «Напиши «СЛОВО» — пришлю <ровно то, что выдаёт лид-магнит>». Если нужно: «Прими запрос в директе».
5. **Хэштеги:** 0–5 по теме, в конце. Без спама.

## Правила
- Кодовое слово одно, в кавычках «ёлочках», совпадает с реестром `funnels/registry.csv`.
- Пиши на «ты», просто, без жаргона. Объясняй, что такое «коннектор» или «агент», если слово встречается впервые.
- Не обещай доход и просмотры. Loore показывает рилсы Claude/ChatGPT, а сценарий пишет Claude.
- Длина 400–900 знаков. Первые 125 знаков — самостоятельная мысль.
- Ссылки в описании не кликаются, поэтому ведём в шапку или через кодовое слово.

## Шаблон
```
<Продолжение хука> 👇

<Боль>. <Что сделал / что изменилось>.

▫️ <пункт>
▫️ <пункт>
▫️ <пункт>

Напиши «<СЛОВО>» — пришлю <что именно>.
```

## Чек-лист
- [ ] Первая строка цепляет без контекста ролика.
- [ ] Обещание = лид-магнит.
- [ ] Слово уникально для поста и есть в реестре.
- [ ] Нет обещаний дохода и просмотров.


## Финальная проверка
Перед отдачей текст проходит скилл `stop-slop` (+ references/russian.md): убрать ИИ-штампы, конкретика вместо общих слов.
