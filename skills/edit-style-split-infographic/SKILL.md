# Промпт: монтаж «голова + главы-инфографика»

## Задача
Возьми нарезанный владельцем A-roll (говорящая голова, его склейки не трогать) + расшифровку с таймингами слов и собери ролик 1080×1920, 60 к/с в Remotion. Ролик делится на ГЛАВЫ (1…N пунктов из текста). Каждая глава — своя карточка с инфографикой, лицо всё время остаётся в кадре в одном из 4 режимов. Определи главы сам по тексту: каждый новый факт/шаг/цифра = новая глава.

## Фон и палитра
- Общий фон в режимах B–D: размытая (blur 40 px, затемнение 35%) копия этого же видео — кадр никогда не «пустой».
- Карточки: тёмные (#141210 → #1d1915, тонкая рамка rgba(255,255,255,.08), скругление 28 px) ИЛИ светлые «скриншотные» (#f6f3ee, для UI/отчётов). Акцент: оранжевый Claude (#d97757 / наш #ff7a1a), белый текст, красный только для «плохо».
- Шрифт заголовков: плотный гротеск КАПСОМ 700–800 (Geist/Inter Tight), 56–72 px; номер главы оранжевым: «1. ТЕСТ ПО КОДУ».

## 4 режима кадра (переключай по правилам ниже)
**A. Лицо на весь экран + слово сверху.** Субтитры ОДНИМ-ДВУМЯ словами капсом, белые, 80–96 px, в верхней трети (y≈280–420), каждое слово меняется по таймингу (без групп). Используй: хук (первые 3–4 с), «переходные» фразы между главами, вывод/«я сделала шпаргалку», CTA.
- В хуке рядом с ключевым словом выскакивает иконка (логотип продукта 96 px, баунс).

**B. Кружок.** Лицо сжимается в круг Ø 520 px (центр, y≈820) за 12 кадров (spring), сверху вылетает UI-скрин (карточка 820 px, лёгкий наклон −2°→0°), под кругом — тезис капсом 2 строки 64 px + мелкая подпись 30 px. Используй: «что случилось» (новость, сравнение) сразу после хука, 3–6 с.

**C. Окно + карточка-глава (основной режим).** Лицо — в верхнем окне (x 0–1080, y 250–820, скругление снизу 28 px), под ним заголовок главы «N. ТЕКСТ» печатается по буквам (30 мс/символ), ниже — карточка-инфографика 940×680 px. Используй: на каждый факт/шаг. Внутри главы инфографика ОЖИВАЕТ под слова:
  - цифры — столбцы растут (0→значение за 20 кадров, ease-out), числа набегают счётчиком, победитель подсвечен оранжевым;
  - «прошёл/сделал» — иконка-объект с покадровой анимацией (экран Gameboy, галочка);
  - «быстрее/дешевле» — стопки монет/полосы, бейдж «−30%»;
  - «показывает правки/ошибки» — светлый UI-скрин, строки подсвечиваются красным/зелёным по очереди, счётчик «0 → 70 правок»;
  - «итог/экономия» — один большой процент «−9%» + маленький бар-чарт.
  - маскот/персонаж бренда может стоять рядом с графиком (у нас — лис Loore ≤ 200 px).

**D. Объект на размытом фоне.** Лица нет 2–4 с: по центру 3D-ish объект (стопка документов + лупа, папка, телефон) с медленным покачиванием, внизу одно слово-субтитр капсом. Используй: «я собрал(а) гайд/шпаргалку» перед CTA.

## Переходы и ритм
- Смена режима: только по смыслу фразы (новая глава / вывод / CTA), с морфом окна (окно ↔ кружок ↔ полный кадр, spring 14/180). Без вспышек и глитчей — стиль спокойный, «дорогой».
- Внутри главы каждые 1–2 с что-то меняется в карточке (новый столбец, подсветка, счётчик). Статичная карточка > 2,5 с — ошибка.
- Номера глав подряд: 1 → 2 → 3… — зритель видит прогресс.

## CTA (последние 4–6 с)
1. Режим A, слова капсом «хочешь / гайд».
2. Внизу (y≈1350) тёмная пилюля «пиши в комментариях» + поле, где кодовое слово ПЕЧАТАЕТСЯ оранжевым капсом с курсором: «SONNET|».
3. Финал: карточка профиля (аватар, ник, био — макет нашего профиля) выезжает снизу + слова «подпишись — ещё интересного у меня в профиле».

## Звук
- Тихий клик на каждую смену слова в режиме A (−30 LUFS), whoosh на смену режима, tick на набегание цифр, «печать» на заголовок главы. Музыка — лёгкий lo-fi −30 LUFS. Итог −14 LUFS.

## Адаптация
- Если владелец смотрит не в камеру — этот кусок уводи в режим C/D (лицо маленькое или скрыто).
- Если фактов мало (1–2) — делай главу длиннее, но с 3–4 событиями внутри.
- Цифры только реальные (из Loore, статистики, источника). Если цифры нет — используй UI-скрин или объект, не выдумывай график.
- Бренд Loore: оранжевый #ff7a1a, Geist; светлые карточки #f4f1ec.
- Безопасные зоны: сверху 250, снизу 350, справа 150 px.

## Чек-лист
- [ ] Первые 3 с — режим A, слово капсом + иконка.
- [ ] Каждая глава пронумерована, у каждой своя живая инфографика.
- [ ] Лицо в кадре почти всё время (кроме режима D ≤ 4 с).
- [ ] Ни одной статичной карточки дольше 2,5 с.
- [ ] Кодовое слово печатается в пилюле, затем карточка профиля.
