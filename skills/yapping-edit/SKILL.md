# Монтаж говорящей головы

Скрипты: `/root/agent/content-factory/tools/`. Remotion-шаблон: `/root/agent/loore-real` (композиция Razbor18 в `src/Edit.tsx`, субтитры `src/subs.ts`, цвет `GRADE` в `src/config.ts`).

## Шаги
1. **Приём.** Скачай части из Telegram (каждая меньше 20 МБ) в `content/<дата>-<слово>/source/`. Проверь ffprobe: разрешение, к/с, поворот.
2. **Расшифровка.** `tools/transcribe.py part1.MOV part2.MOV` создаёт `part*.json` с таймингами слов.
3. **EDL.** `tools/build_edl.py part1.MOV part2.MOV > edl.json` режет по паузам больше 0,3 с и помечает дубли (оставляет последний). Прочитай `edl.md` целиком и поправь вручную:
   - оговорки и обрывки фраз → `drop: true`;
   - концовку, где владелец выключает камеру → обрезать;
   - куски, где он смотрит не в камеру (кадры из `sheet.py`) → оставить звук, сверху поставить вставку.
4. **A-roll.** `tools/render_aroll.py edl.json source/ public/clips/aroll.mp4` создаёт `words_aroll.json`.
5. **Remotion.** Скопируй шаблон `loore-real` (без node_modules: сделай symlink или `npm i`) и правь его:
   - **Цвет:** `GRADE = 'contrast(1.18) brightness(0.94) saturate(0.82) sepia(0.10)'` плюс виньетка, только на лицо. Перед финалом покажи «до/после».
   - **Субтитры:** из `words_aroll.json`, 2 строки, ниже лица. Ключевые слова — акцентом #ff7a1a. Хук крупно на первые 2 с.
   - **Вставки:** по `inserts.md`. Каждая — отдельный клип в `public/clips/`, локальные кадры через Sequence. Не подгоняй длину через playbackRate у OffthreadVideo.
   - **Значок Claude:** цвет #d97757 только на знаке Claude. Логотип Loore — вместо «читерского» места, если сценарий так требует.
   - **Безопасные зоны:** сверху 250, снизу 350, справа 150 px.
6. **Проверка.** `node tools/stills.mjs` (COMP=…) → `sheet.py` даёт лист кадров → отправь владельцу → «ок».
7. **Рендер.** `npx remotion render <Comp> out/edit.mp4`, затем `tools/finalize.sh out/edit.mp4 final.mp4` (−14 LUFS, стерео). Если файл больше 50 МБ — версия `final_tg.mp4` (crf или битрейт ниже) для Telegram.
8. **Обложка.** Кадр с лицом и хук крупно → `cover.jpg` 1080×1920. Важное — в центральной зоне 1080×1350.

## Чек-лист качества
- [ ] Нет пауз больше 0,3 с, нет повторов фраз, нет «ээ» в начале куска.
- [ ] Хук звучит в первые 0,5 с, не через 2 с.
- [ ] Субтитры совпадают с речью (сверены с words_aroll.json), без ошибок в «Loore», «Claude» (Whisper пишет «лур», «клот»).
- [ ] Вставки не закрывают лицо там, где он говорит в камеру.
- [ ] Цвет не пережжён: кожа не оранжевая, тени не залиты.
- [ ] Громкость −14 LUFS ±1, пик не выше −1 dBTP, стерео.
- [ ] Концовка: кодовое слово крупно, затем подпишись.
- [ ] Длина совпадает с планом; в 9:16 ничего важного не уходит в безопасные зоны.

## Правила ритма и звука (взяты из OpenMontage, github.com/calesthio/OpenMontage — skills/creative/short-form.md, sound-design.md)
- Визуальная смена каждые 1–3 с; статичный план > 3 с — ошибка. Паттерн-интеррапты каждые 2–4 с дают ~58% удержания против ~41% у статичной головы.
- Кадр 1: уже движение + текст хука в первые 0,5 с, голос сразу, без интро.
- Ориентиры удержания: 3 с ≥ 70%, 15 с ≥ 60%, 30 с ≥ 50%.
- Текст на экране (не субтитры): 3–5 слов, в верхних 40% безопасной зоны, появление 0,2–0,3 с.
- SFX: whoosh 400–500 мс на переходах (−18…−12 dB), pop < 200 мс на появлении текста, click < 100 мс на UI, impact < 300 мс на ключевой цифре (−12…−6 dB). Whoosh ставить на 10–20 мс РАНЬШЕ визуального перехода, пик — на момент максимальной смены.
- Музыка под голосом на 18–20 dB тише голоса, инструментальная, без дропов; срезать 2–4 кГц у музыки.
- Если всё-таки режем паузы (только с согласия владельца, см. память aroll-cutting): по энергии звука, порог −35 dB, тишина ≥ 0,5 с, паддинг 0,08 с — не по таймингам слов.
- Стили монтажа по референсам: `edit-style-apple-motion`, `edit-style-split-infographic`, `edit-style-split-screen`.

## Правила из эфира EdgeLab 22.09 (montage-pipeline)
- Резать только по энергии звука; таймкоды расшифровки — для понимания смысла, не для реза.
- Дубли и брошенные заходы НЕ искать автоматически: агент предлагает список интервалов на выброс по расшифровке → владелец подтверждает → рез притягивается к тишине.
- Порог тишины от речи (75-й перцентиль −6,5 дБ, коридор −46…−30), паузы ≥260 мс, запас 90/130 мс, 600 мс в конце; ускорение 1,3 — последним.
- Хук на экране виден целиком с нулевого кадра, не собирать по словам.
- Спикер во всю ширину, без размытых полей; раскладка меняется ~каждые 3 с.
- Безопасные зоны: сверху 115 px, полоса 1760–1840 закрыта, субтитры ≤24 символа.
