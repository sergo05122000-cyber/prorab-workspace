# Промпт: монтаж в стиле «Apple-моушн»

## Задача
Собери вертикальный ролик 1080×1920, 60 к/с в Remotion **без говорящей головы**: только голос за кадром (или музыка + текст) и моушн-графика в эстетике Apple. Входные данные: аудио/голос (+ расшифровка с таймингами слов), список шагов (обычно 3), материалы для каждого шага (скрины, иконки, UI-элементы, цифры), кодовое слово для CTA. Если материалов к шагу нет — нарисуй UI-карточку сам (кнопка, виджет, переключатель, профиль), не вставляй пустоту.

## Визуальный язык
- Фон: чистый белый #FFFFFF; тени мягкие (0 20px 60px rgba(0,0,0,.12)); скругления 36–48 px.
- Шрифт: SF Pro (если нет — Inter/Geist): заголовок «Шаг N.» 700, 84–96 px, плотный трекинг −0.03em; подзаголовок 400, 52–60 px, одной строкой под ним.
- Акцент-плашка: пилюля с заливкой фирменного цвета (в референсе коралловый #E8604C, у нас — #ff7a1a), белый текст 34 px («шрифт Apple», «bounce it!»).
- Сплошная цветная «волна» (фирменный цвет) внизу кадра — рваный пиксельный край, медленно «дышит» (смещение по Y ±20 px, 2 с цикл). Появляется на обложке и как шторка-переход.
- Иконки/карточки по центру кадра, ширина 520–620 px, в квадрате со скруглением и мягким градиентом (голубой → белый, зелёный glow и т.п.).
- Минимум текста на экране: 1 заголовок + 1 плашка + 1 объект.

## Структура (по времени, масштабируй под длину голоса)
| Блок | Доля | Что на экране |
|---|---|---|
| Обложка-хук | 0–12% | маленький бейдж автора (аватар + ник) сверху; иконка-объект; большой заголовок; плашка; строка «повтори в N шага!»; волна внизу |
| Переход | 0,4 с | «жидкое стекло»: размытая стеклянная капля пролетает через заголовок и «съедает» его (scale 0→1.4, blur 20px, лёгкая хроматическая аберрация) |
| Шаг 1…N | по ~20–25% | заголовок «Шаг N.» печатается (набор по буквам 25–35 мс/символ, подзаголовок допечатывается вторым), затем по центру появляется объект шага с баунсом; внутри шага 2–4 смены объекта под слова |
| «Что нужно?» | ~10% | заголовок в рамке-выделении (как выделенный текст в редакторе: синяя рамка с ручками), список с точками дописывается по пунктам |
| CTA | последние ~12% | «пиши "+"» (кодовое слово в синих кавычках) над тёмной плашкой-папкой; кнопка на плашке «превращается» в «забрать всё!», снизу «скачай материалы» |

## Анимации (точные параметры)
- Баунс появления: spring(damping 12, stiffness 220, mass 0.7), scale 0.6→1.0 с перелётом ~1.06, opacity 0→1 за 6 кадров.
- Смена объекта внутри шага: старый — scale 1→0.92 + fade 8 кадров; новый — баунс. Кнопки внутри UI «нажимаются»: scale 1→0.94→1 за 10 кадров + звук клика.
- Набор текста: по символу, курсор не нужен; на последней букве — микро-скейл заголовка 1→1.02→1.
- Волна-шторка между шагами: волна поднимается снизу и закрывает кадр за 12 кадров, на следующем шаге уходит вверх (или наоборот) — переход «через цвет».
- Каждые 1,5–2,5 с на экране обязано что-то меняться (новый элемент, нажатие, смена объекта). Пауза > 3 с без движения — ошибка.

## Звук
- UI-звуки на каждое событие: появление — soft pop; нажатие — click; печать — тихий keyboard tick (громкость 0.15); шторка — whoosh; финальная кнопка — success chime.
- Музыка лёгкая, −28…−32 LUFS под голосом. Финал −14 LUFS.

## Адаптация под наш материал
- Нет голоса? Делай текстовый ролик: заголовки дольше держатся (1,5× от чтения), музыка громче (−20 LUFS).
- Шагов больше 3 — сжимай каждый шаг, но не меньше 3 с.
- Если объект шага — длинный скрин (чат, таблица) — показывай его в карточке с автоскроллом, а не целиком мелко.
- Бренд Loore: вместо кораллового — #ff7a1a, вместо синего выделения — тёмный #1a1512; зелёный только для «готово».
- Безопасные зоны Reels: сверху 250, снизу 350, справа 150 px — заголовки и CTA внутри них.

## Чек-лист
- [ ] Первый кадр — уже обложка (не белый пустой кадр).
- [ ] Ни одной паузы > 2,5 с без движения.
- [ ] На каждом шаге есть реальный объект (скрин/иконка/UI), не только текст.
- [ ] Звук на каждое событие, без перегруза.
- [ ] CTA: кодовое слово крупно + что человек получит.
