# Микроворонка под пост

Путь: комментарий со СЛОВОМ → автоответ в директ → ссылка на бота или статью → лид-магнит → цепочка → Loore (VIRAL) или лист ожидания клуба.

## Шаги
1. **Слово.** Короткое, по теме поста, не повторяется в реестре. Варианты для триггера:
   - кириллица и латиница: «разбор / razbor»;
   - частые опечатки;
   - неправильная раскладка: «hfp,jh»;
   - регистр не важен.
2. **Лид-магнит.** Статья по скиллу `lead-article`, которая полностью закрывает обещание поста. Внутри 2 мягкие ссылки: Loore с кодом VIRAL (и/или лист ожидания EdgeLab).
3. **Директ (ChatPlace).**
   - Триггер: комментарий со словом под конкретным медиа (`automations_triggers_list_instagram_media`).
   - Публичный ответ в комментарии (2–3 варианта по очереди): «Отправил в директ 📩».
   - Сообщение в директ: 1 строка ценности + кнопка «Забрать» → бот/статья. Просьба «прими запрос», если человек не подписан.
   - Окно 24 часа: дожим в директ только в течение 24 часов после ответа человека.
4. **Бот (Telegram) и цепочка.** День 1: 4 касания (сразу материал → +1 ч «получилось?» → +4 ч кейс → вечер оффер). Дни 2–7: по 1 касанию в день — польза, кейс, возражение, оффер. Каждое касание с кнопкой.
5. **Реестр.** Строка в `funnels/registry.csv`:
   `date,word,variants,post_url,magnet_url,automation_id,offer,status,triggers,clicks,regs,pays`
6. **Папка** `funnels/<дата>-<слово>/`: `funnel.md` (схема), `dm.txt`, `chain.md`, `magnet.md`.

## Правила
- До «ок» владельца ничего не создаём и не включаем в ChatPlace: готовим схему в файлах и показываем.
- Каждая ссылка на Loore — с кодом VIRAL (https://loore.ai/r/viral или t.me/looreaibot?start=ref_viral).
- Пока у EdgeLab нет рефералки, вместо ссылки ставим «записаться в лист ожидания воркшопа» (тег в боте).
- Отписка в каждом касании цепочки.

## Чек-лист
- [ ] Слово уникально, варианты написания добавлены.
- [ ] Обещание поста = содержимое лид-магнита.
- [ ] Ссылка рабочая, код VIRAL на месте.
- [ ] Тест: комментарий с тестового аккаунта → директ пришёл (после включения).
- [ ] Строка в реестре заполнена.
