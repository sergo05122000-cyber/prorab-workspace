# Разбор карусели → рецепт повторения

## Вход
Все слайды в оригинальном размере (Loore ig_download index=1..N, 0,5 кредита за слайд), подпись (ig_media), цифры (лайки, комментарии, ×N к медиане автора из tracking_feed).
Склей лист миниатюр (4 в ряд) для общего взгляда, но каждую деталь проверяй на слайде в полном размере.

## Промпт разбора (выполняй по пунктам, пиши конкретно: размеры в % от кадра, цвета hex, примерный шрифт)

**1. Паспорт.** Автор, дата, слайдов, лайки / комментарии / ×N, кодовое слово, что отдают за слово.

**2. Обложка: 6 деталей.**
- Картинка: что именно (реальное фото человека / 3D-объект / скрин / коллаж), откуда она скорее всего (пресс-фото, генерация, рендер), сколько кадра занимает, куда смотрит объект.
- Затемнение: тип (градиент снизу / плашка / нет), с какого % высоты, до какого цвета.
- Заголовок: строк, слов, регистр, жирность, шрифт (ближайший бесплатный аналог), размер в % ширины, выравнивание, цвет, где по высоте.
- Подзаголовок: есть ли цифра, размер относительно заголовка.
- Призыв листать: текст, стрелка, где.
- Формула текста обложки: [громкое имя / срочная новость / «увольняйте X» / цифра-результат] + [обещание].

**3. Сетка внутренних слайдов.** Фон (hex), поля, где заголовок, ширина карточек, радиус углов, рамка (толщина, цвет), тень, межстрочный, выравнивание (центр/лево). Сколько разных типов слайдов и как они чередуются.

**4. По каждому слайду строка таблицы:** № · роль в механике (обещание / факт / переворот «НО» / решение / доказательство / призыв) · текст дословно · что выделено жирным · визуальный элемент (реальный скрин чего / фото / таблица / кнопка-плашка / иконка) · откуда этот элемент взять нам.

**5. Доказательства.** Какие слайды держатся на реальных экранах (статистика, интерфейс Claude, файлы в Telegram, таблица результата). Повторяет ли автор один и тот же скрин-доказательство из карусели в карусель (это нормально).

**6. Текстовая механика.** Сколько слов на слайд, где переворот, где личная ставка, какие слова жирные (обычно глаголы-действия и цифры), как построен CTA (вопрос «Хочешь себе такой…?» → «Пиши в комментариях» → слово крупно → что пришлю + скрин файла).

**7. Почему не нейрослоп.** 3–5 причин, видных глазами (реальные скрины, одна сильная картинка, единая система, мало текста, живые цифры автора).

**8. Рецепт для @prorab.ai.**
- Что берём один в один (сетка, типы слайдов, порядок механики, CTA).
- Что меняем (тема — боль нашего зрителя, наши реальные скрины Loore/Claude/Instagram, наше кодовое слово LOORE/АУДИТ/КОМАНДА).
- Список ассетов, которые надо добыть до вёрстки: картинка обложки (как получим: рендер Blender / генерация Сергеем в его ChatGPT / свободная лицензия / наш скрин), каждый скрин (что снять и где).
- Чего НЕ берём: чужие фото людей без права, чужие цифры, чужой файл-магнит.

## Выход
research/carousels/<папка>/teardown.md + sheet.jpg. В конце — одной строкой главный приём, который делает эту карусель.
