# Карусель

## Структура (5–10 слайдов)
1. **Обложка** — обещание + цифра или объект. ≤ 8 слов крупно, подзаголовок ≤ 10 слов. Пример: «Как Claude разбирает чужой рилс за 1 минуту».
2. **Проблема** — узнаваемая боль: «Просишь ChatGPT вирусный сценарий, а он Instagram не видит».
3–7. **Шаги** — один шаг на слайд: номер, действие, скрин или мокап. Крупный текст, 15–30 слов на слайд.
8. **Доказательство** — реальный скрин: ×N, ответ Claude, кадры.
9. **Итог** — что получишь, 3 пункта.
10. **Призыв** — «Напиши «СЛОВО» в комментариях — пришлю <…>». Плюс «Сохрани, чтобы не потерять».

## Дизайн
- Размер 1080×1350, поля 80 px, шрифт Geist (заголовки 700, 72–96 px; текст 400, 36–44 px).
- Светлая тема Loore: фон #f4f1ec, карточки #fff, текст #1a1512 / #6f6a62. Акцент #ff7a1a — не больше 3 мест на слайд.
- Номер слайда и «листай →» на обложке. Ник @prorab.ai маленьким внизу.
- Скрины — в рамке-карточке со скруглением 24 px и тенью. Личные данные замазать.

## Сборка
1. `slides.json` (заголовок, текст и картинка для каждого слайда).
2. HTML-шаблон → Playwright screenshot каждого слайда (`/root/agent/loore-promo/research/page.js` как образец).
3. Лист миниатюр (все слайды на одном jpg) → «ок» владельца.
4. PNG в `content/<дата>-<слово>/carousel/`, описание — по скиллу `caption-formula`.

## Ролик ↔ карусель
- Рилс → карусель: хук → обложка, шаги из сценария → слайды, кадр-доказательство → слайд 8.
- Карусель → рилс: обложка → хук, каждый слайд → 1 фраза + вставка.

## Чек-лист
- [ ] Обложку можно понять за 1 секунду с телефона.
- [ ] На каждом слайде одна мысль.
- [ ] Текст не мельче 36 px.
- [ ] Кодовое слово совпадает с реестром.

## Журнал правок Сергея
- 2026-10-15: карусель по механике @matvienko (фото, слои, облачко, папки, выделенный текст) → «Ок» после замены его фото на CC0.
- 2026-10-16: автопилотная карусель из шаблона tools/carousel (только текст на кремовом фоне, тема — разбор чужого рилса про резюме) → «отстой, сплошной нейрослоп». Причины: нет картинки и реальных экранов, все слайды одного вида, текст-комментарий вместо пользы для зрителя, тема не про его аудиторию. Правило: никаких чисто текстовых шаблонов; каждая карусель копирует визуал и структуру реального залетевшего референса (слои, фото, скрины), тема — боль его зрителя.
- 2026-10-16 22:00: карусель по системе Палия (3D-обложка Blender + серые карточки + таблицы-макеты) → «Обложка ещё норм, внутрянка не очень». Сергей сам пришлёт референсы внутренних слайдов. Вывод: обложка-3D годится; внутренние слайды в виде карточек с текстом и нарисованных таблиц/макетов не тянут — ждём его референсы, верстаем внутрянку строго по ним.
