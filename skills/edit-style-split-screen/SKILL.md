# Промпт: монтаж «сплит-скрин»

## Задача
Нарезанный владельцем A-roll (склейки не трогать) + расшифровка → ролик 1080×1920, 60 к/с, 20–40 с. Кадр большую часть времени разделён горизонтально: **верх — демонстрация** (что говорится, то и показывается), **низ — лицо**.

## Раскладка
- Линия раздела y = 900–960. Низ: лицо, кроп A-roll так, чтобы глаза были на ~1/3 нижней половины (y≈1200), лёгкий зум 1.05 → 1.12 за длину плана.
- Верх: белый #FFFFFF (или светлый #f4f1ec бренда), контент по центру, поле 80 px.
- Субтитр: чёрная плашка (#111, скругление 10 px, паддинг 10×22) с белым текстом 46–52 px, 2–4 слова, ПО ЦЕНТРУ ЛИНИИ РАЗДЕЛА — плашка «сшивает» две половины. Слова меняются группами по фразе, без подсветки.
- Акцент-слово/кодовое слово: крупный белый капс с чёрной обводкой 6 px, 110–130 px, в кавычках «ВЫХОДНЫЕ», поверх раздела, с баунсом.

## Что ставить в верхнюю зону (по смыслу фразы)
1. **Маскот/иллюстрация действия** — простая пиксельная/плоская фигура (у нас — лис Loore), к которой по словам добавляются предметы: «студия» → софтбокс + микрофон, «видео» → рамка видоискателя с «● REC 00:00:00» и хлопушка. Каждый предмет — баунс + щелчок.
2. **Логотип/иконка** упомянутого сервиса (GitHub, Claude, Loore) — одна по центру, баунс.
3. **UI-процесс** — фейковые, но честные по смыслу экраны агента: «Searching the web…» с печатающимся запросом и спиннером; «Adding music» с карточкой трека, вейвформой и таймлайном. Состояние меняется каждые 1–2 с.
4. **Полноэкранный B-roll** (без лица) на 1–3 с, когда говорится «внутри целая…/смотри, что получается» — скриншоты результата, размытый фон.
5. **Полное лицо** (без сплита) на 1–2 фразы — для перечислений («а четвёртый…») и смены ритма; субтитр-плашка тогда по центру груди.

## Ритм
- Смена содержимого верхней зоны каждые 1,5–3 с, строго по ключевым словам расшифровки (существительные: студия, видео, GitHub, сценарий, озвучка, музыка).
- Не больше 2 фраз подряд в одном и том же сплите — затем полное лицо или B-roll.
- CTA (последние 3–4 с): верх — превью продукта/лид-магнита (сайт, курс) в рамке браузера с маленьким окном лица (PIP) внутри, на разделе — капс-слово «ВЫХОДНЫЕ», в плашке — «напиши… и я вышлю доступ».

## Звук
Щелчок/поп на каждое появление предмета (−18 dB), «печать» на поиск, лёгкий whoosh на смену режима (сплит ↔ полное лицо ↔ B-roll), фоновая музыка −28…−30 LUFS. Итог −14 LUFS.

## Адаптация
- Если демо нечего показать — маскот + предмет-метафора (не пустой белый).
- Если в нижнем кадре владелец отворачивается — на это время полноэкранный B-roll.
- Бренд Loore: верх #f4f1ec, плашка #1a1512, акцент #ff7a1a; маскот — лис (≤ 600 px исходник).
- Безопасные зоны: субтитр-плашка и капс-слово не выше 250 px сверху и не ниже 1570 px.

## Чек-лист
- [ ] Первый кадр — уже сплит с объектом сверху и первым субтитром.
- [ ] Каждое ключевое слово имеет визуал сверху.
- [ ] Минимум 2 смены режима (сплит / полное лицо / B-roll) за ролик.
- [ ] CTA-слово крупным капсом на разделе.
