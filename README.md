# prorab-workspace

Рабочее пространство ИИ-агента контент-завода **@prorab.ai**: инструкции, агенты, скиллы и инструменты, по которым Claude Code сам делает рилсы, карусели, мультики и воронки.

Агент живёт на сервере 24/7 и получает задачи голосом через Telegram. Этот репозиторий — его «должностные инструкции»: открываешь в Claude Code с любого устройства, и агент работает по тем же правилам.

## Что внутри
| Папка | Что это |
|---|---|
| `CLAUDE.md` | Главная инструкция: что продаём, аудитория, жёсткие правила, автоматизация |
| `MAP.md` | Карта: где что лежит на сервере и как устроен конвейер |
| `agents/` | Агенты-сотрудники: продюсер, монтажёр, каруселист, трафик, продукт, аналитик, приёмщик |
| `skills/` | Свои скиллы: сценарий рилса, банк хуков, подписи, карусели, стили монтажа, микроворонки, сериалы |
| `skills/EXTERNAL.md` | Чужие открытые скиллы, которые мы используем, со ссылками |
| `tools/` | Расшифровка речи, вырезка пауз, приёмка ролика перед отправкой, проверка перед платной генерацией |

## Как пользоваться
1. Склонируй репозиторий и открой папку в Claude Code.
2. Скиллы скопируй в `.claude/skills/`, агентов — в `.claude/agents/`.
3. Дай задачу словами: «сделай сценарий рилса про …», «смонтируй это видео», «собери карусель».

Без ключей, личных данных и клиентских материалов: они хранятся только на сервере.
