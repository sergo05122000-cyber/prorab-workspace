# Карта конвейера

```
Голосовое в Telegram → агент (Claude Code на сервере)
   ├─ идея / сценарий ── creative-producer + reel-script, hook-bank, storytelling
   ├─ монтаж говорящей головы ── video-editor + yapping-edit, tools/trim_pauses.py
   ├─ мультик ── движок 2d-video (код рисует каждый кадр, без генеративных моделей)
   ├─ карусель ── carousel-maker + carousel
   ├─ подпись ── caption-formula
   ├─ воронка ── traffic-director + micro-funnel (кодовое слово → автоответ → бот)
   ├─ приёмка ── reviewer + tools/qc.py --fix (без «ПРИЁМКА ПРОЙДЕНА» не отправляем)
   └─ отчёт ── analyst, каждый понедельник в Telegram
```

## Папки на сервере
- `content-factory/` — контент-завод: `content/<дата>-<слово>/` (сценарий, суфлёр, монтаж), `funnels/`, `analytics/`, `research/`, `bot/` (лид-бот), `tools/`.
- `2d-video/` — движок мультиков: `projects/<slug>/` (сценарий, кадры, звук, рендер).
- `cf-reels/` — Remotion-кит графики для рилсов.
- `music-library/` — музыка без авторских проблем.
- `crm/` — мини-CRM заявок.
- Память агента — отдельно, в зашифрованном бэкапе.

## Правила работы
- Каждый этап сдаётся владельцу кадрами или превью и ждёт «ок».
- Публикация, рассылки, деплой — только после «ок».
- Тяжёлые задачи — через очередь `heavy <команда>` (на сервере 3,8 ГБ ОЗУ).
